# Contributing to SmartSchema Extract API Client

Thank you for your interest in contributing!

## How to contribute

1. **Open an Issue** before submitting a pull request — describe the problem or feature
2. **Fork** the repository and create a branch: `feature/your-feature-name`
3. **Add examples** in `/examples` for new use cases
4. **Update docs** in `/docs` if your change affects usage
5. Submit a **Pull Request** with a clear description

## Code style

- JavaScript: ES Modules (`import/export`), no CommonJS
- Python: type hints encouraged, Python 3.9+
- Comments in English

## Questions?

Open a Discussion or reach us via [RapidAPI support](https://rapidapi.com/TU_USUARIO/api/smartschema-extract).
