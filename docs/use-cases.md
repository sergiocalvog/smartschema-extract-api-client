# Use Cases — SmartSchema Extract API

## Invoice and receipt parsing
Extract invoice numbers, dates, line items, taxes and totals from PDF-to-text or raw invoice content.
→ See `examples/invoice-parser.js`

## E-commerce product normalization
Scrape product pages and normalize prices, ratings, availability and specs to a consistent schema.
→ See `examples/ecommerce-scraper.js`

## Email entity extraction
Extract meeting dates, contact details, budget figures and action items from email bodies.
→ See `examples/email-parser.py`

## ETL pipelines
Use as a transformation step in n8n, Make, or Zapier to normalize legacy data without fixed parsers.

## CI/CD data validation
Validate that incoming webhook payloads or third-party API responses conform to your expected schema.

## Document processing
Convert scanned PDFs (OCR output) into structured database-ready records.
